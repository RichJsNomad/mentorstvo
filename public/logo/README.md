# DevMentor — Logo Pack

## Файлы
- `devmentor-logo.svg` — основной знак, gradient cyan→blue (#06B6D4 → #3B82F6)
- `devmentor-logo-mono-light.svg` — белый знак на тёмной плашке (для тёмных фонов)
- `devmentor-logo-mono-dark.svg` — тёмный знак (для светлых фонов)
- `devmentor-lockup-dark.svg` — знак + надпись DevMentor (тёмная тема, белая надпись)
- `devmentor-lockup-light.svg` — знак + надпись (светлая тема, тёмная надпись)
- `devmentor-logo-512.png` / `devmentor-logo-1024.png` — растровые версии
- `favicon-64.png` — для favicon
- `devmentor-lockup-dark-1200.png` — растровый lockup для соцсетей/OG-image

## Концепт
Terminal caret `>_` — отсылка к командной строке и разработке.

## Цвета
- Primary gradient: linear-gradient(135deg, #06B6D4, #3B82F6)
- Иконка внутри: #FFFFFF
- Минимальный отступ вокруг: 12.5% от стороны (clear space)
- Минимальный размер: 16×16 (favicon), 24×24 рекомендованный минимум

## Шрифт wordmark
Space Grotesk, weight 600, letter-spacing −0.025em.
